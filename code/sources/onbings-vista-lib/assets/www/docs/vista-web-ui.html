VISTA Web Interface — User Guide

Opening this guide from the console: click the Help button (the question‑mark icon, ❔) at the top‑right of the VISTA console header, or press F1 (or Shift + ?). The guide opens in a new browser tab. It is served locally by the device (docs/vista-web-ui.html), so it works without Internet access.

1. Accessing the interface

The entry point is:

https://xts-009:7000

Replace xts-009 with the host name or IP of your device.

The service uses a self‑signed TLS certificate, so on the first connection the browser displays a security warning ("Your connection is not private" / "Not secure"). This is expected. Accept/continue to proceed to the site — you will subsequently see the Not secure marker in the address bar, which is normal for a self‑signed certificate on a local device.

Once the page loads it calls GET /vista/v1/config; the main controls stay hidden until the device configuration has been retrieved and the connection is reported as Connected.
