# Introduction

This project uses [semantic versioning](https://semver.org/)

Consequently, you should increment

What  | When
-     | -
MAJOR | When you make incompatible API changes
MINOR | When you add functionality in a backward compatible manner
PATCH | When you make backward compatible bug fixes (that do not affect the API)

Upon releasing a version, Teamcity will increment the PATCH version automatically (as it is a safe assumption to make).

**It's your responsibility to update version number in a proper way based on modifications !**

In case of doubt, refer to the [specification](https://semver.org/)
